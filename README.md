# 📊 Business Sales Insights Dashboard (Power BI)

## 📌 Overview

This project presents an interactive Power BI dashboard analyzing business sales data to uncover trends, product performance, and regional insights.

## 🎯 Objectives

* Track total sales and quantity sold
* Identify top-performing products
* Analyze sales across different regions
* Enable dynamic filtering using slicers

## 📊 Key Insights

* Sales show variation across months indicating trend patterns
* A small number of products contribute significantly to revenue
* Certain regions (e.g., UK & India) dominate overall sales

## 🛠 Tools Used

* Power BI
* DAX
* Data Visualization
